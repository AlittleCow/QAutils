# QAUtils KT Plugin 使用指南

## 概述

QAUtilsKTPlugin 是一个为 KT 系统开发的插件，提供了技术指标计算、服务器通信和数据处理功能。插件已成功编译为32位DLL文件。

## 安装和配置

### 1. 文件位置

编译完成后，以下文件位于 `build/bin/Release/` 目录：
- `QAUtilsKTPlugin.dll` - 主插件文件
- `libzmq-mt-4_3_5.dll` - ZeroMQ依赖库

### 2. 插件注册

将 `QAUtilsKTPlugin.dll` 复制到 KT 系统的插件目录，通常为：
```
KT安装目录/Plugins/
```

### 3. 依赖库

确保 `libzmq-mt-4_3_5.dll` 与插件DLL在同一目录，或者在系统PATH中。

## 功能模块

### 1. 技术指标计算

插件提供以下技术指标：

#### EMA (指数移动平均)
- **函数名**: `EMA`
- **参数**: 周期数
- **用法**: 在KT公式中使用 `EMA(CLOSE, 12)` 计算12周期EMA

#### MACD
- **函数名**: `MACD`
- **参数**: 快线周期, 慢线周期, 信号线周期
- **用法**: `MACD(CLOSE, 12, 26, 9)`

#### RSI (相对强弱指标)
- **函数名**: `RSI`
- **参数**: 周期数
- **用法**: `RSI(CLOSE, 14)`

### 2. 服务器通信功能

#### 心跳检测
- **函数名**: `KTServer_Heartbeat`
- **功能**: 检测与量化服务器的连接状态
- **返回**: 1.0表示连接正常，0.0表示连接异常

#### 服务器信息
- **函数名**: `KTServer_GetInfo`
- **功能**: 获取服务器运行状态信息
- **返回**: 服务器状态数据数组

#### 连接管理
- **函数名**: `KTServer_Connect` / `KTServer_Disconnect`
- **功能**: 建立或断开与服务器的连接

#### 数据发送
- **函数名**: `KTServer_SendKBar`
- **功能**: 向服务器发送K线数据

#### SMA计算
- **函数名**: `KTServer_CalculateSMA`
- **功能**: 使用服务器计算简单移动平均

## 在KT中使用

### 1. 公式编写示例

```pascal
// 计算12周期EMA
EMA12 := EMA(CLOSE, 12);

// 计算MACD指标
MACDLine := MACD(CLOSE, 12, 26, 9);

// 计算RSI
RSI14 := RSI(CLOSE, 14);

// 检查服务器连接
ServerStatus := KTServer_Heartbeat();
```

### 2. 条件判断

```pascal
// 基于EMA的交易信号
IF EMA(CLOSE, 12) > EMA(CLOSE, 26) THEN
    BUY;

// 基于RSI的超买超卖
IF RSI(CLOSE, 14) > 70 THEN
    SELL; // 超买
IF RSI(CLOSE, 14) < 30 THEN
    BUY;  // 超卖
```

### 3. 服务器功能使用

```pascal
// 检查服务器状态
IF KTServer_Heartbeat() > 0 THEN
BEGIN
    // 服务器在线，可以使用服务器功能
    ServerSMA := KTServer_CalculateSMA();
END;
```

## 配置说明

### 1. 日志配置

插件会在运行目录生成 `kt_plugin.log` 日志文件，记录：
- 插件初始化信息
- 函数调用记录
- 错误和警告信息
- 服务器通信状态

### 2. 服务器配置

默认服务器配置：
- **地址**: localhost
- **端口**: 5555
- **协议**: ZeroMQ

如需修改服务器配置，请联系技术支持。

## 故障排除

### 1. 插件加载失败

**可能原因**:
- DLL文件损坏或版本不匹配
- 缺少依赖库
- KT版本不兼容

**解决方案**:
1. 检查DLL文件完整性
2. 确保所有依赖库存在
3. 查看KT错误日志

### 2. 函数计算错误

**可能原因**:
- 输入数据不足
- 参数设置错误
- 内存不足

**解决方案**:
1. 检查数据长度是否满足计算要求
2. 验证参数范围和类型
3. 查看插件日志文件

### 3. 服务器连接问题

**可能原因**:
- 服务器未启动
- 网络连接问题
- 端口被占用

**解决方案**:
1. 确认量化服务器正在运行
2. 检查网络连接
3. 验证端口配置
